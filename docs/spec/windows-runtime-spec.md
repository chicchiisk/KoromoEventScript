# KoromoEventScript Windows ランタイム仕様書

KoromoEventScript Runtime は、Windows 11 上で KoromoEventScript のビルド成果物を単体実行するための配布用プレイヤーである。

本仕様書では、Windows ランタイムの対象環境、起動方法、入力ファイル、描画、音声、入力、標準 UI、セーブデータ、診断、配布成果物を定義する。

## 基本方針

- Windows 11 のみをサポートする。
- 実装言語は C# とする。
- アプリケーション基盤は WinUI 3 と Windows App SDK を用いる。
- グラフィクス描画には Win2D を用いる。
- 配布用プレイヤーとして、一般ユーザーが `kes publish --target windows` の成果物を起動して遊べることを優先する。
- 開発時には `kes run` から起動され、ビルド成果物の確認にも利用できる。
- ランタイムは `.kc` / `.kel` の生ソースを直接実行しない。
- ランタイムは CLI が生成した `.klib`、`manifest.json`、素材を読み込み、VM を通じてイベントを実行する。
- `.klib` は現行の VM 実行用中間表現であり、ファイル形式、instruction schema、manifest 参照契約は [`.klib` 中間表現仕様](k-intermediate-representation-spec.md)に従う。
- `.klib` は旧称または移行前の表記として扱い、新規仕様と新規成果物では `.klib` を正とする。

## 用語

| 用語 | 意味 |
|---|---|
| Windows ランタイム | Windows 11 向けの KoromoEventScript 単体実行基盤 |
| プレイヤー | 配布物内の実行アプリケーション |
| VM | `.klib` ファイルを読み取り、イベントスクリプトを実行する仮想マシン |
| `.klib` | CLI が生成する VM 実行用中間表現。詳細は [`.klib` 中間表現仕様](k-intermediate-representation-spec.md)で定義する |
| `.klib` | `.klib` の旧称または移行前表記。現行仕様では `.klib` を正とする |
| manifest | CLI が生成する `manifest.json`。入力ファイル、`.klib`、素材、ローカライズ情報を含む |
| 制作座標系 | シナリオ演出と UI 配置の基準となる論理座標 |
| 表示座標系 | 実際のウィンドウまたはフルスクリーン上の物理表示領域 |
| 画面状態 | 背景、立ち絵、UI、選択肢、トランジション状態など、表示を復元するための状態 |

## 対象環境

| 項目 | 内容 |
|---|---|
| OS | Windows 11 |
| 言語 | C# |
| UI 基盤 | WinUI 3 |
| アプリ基盤 | Windows App SDK |
| グラフィクス | Win2D |
| 音声 | WinUI / WinRT 標準のメディア再生機能 |

Windows 10 以前、macOS、Linux は対象外とする。

## ランタイム構成

Windows ランタイムは、次の責務を持つモジュールから構成する。

| モジュール | 役割 |
|---|---|
| 起動制御 | コマンドライン引数、設定、manifest を読み込み、ランタイムを初期化する |
| VM 実行 | `.klib` を読み込み、命令列を実行する |
| リソース管理 | manifest に基づいて画像、音声、ローカライズ辞書を解決する |
| 描画 | Win2D により背景、actor、トランジション、UI を描画する |
| 音声 | BGM、SE、Voice の再生、停止、音量制御を行う |
| 入力 | マウス、キーボード、ゲームパッド相当の入力をプレイヤー操作へ変換する |
| UI | メッセージウィンドウ、選択肢、履歴、セーブ、ロード、設定などを提供する |
| セーブ管理 | セーブデータ、オートセーブ、既読情報、ユーザー設定を保存する |
| 診断 | エラー表示、ログ、デバッグ表示、プロファイル情報を扱う |

## 起動方法

Windows ランタイムは、開発時には CLI の `kes run` から起動される。
配布時には `kes publish --target windows` で生成された実行ファイルをユーザーが直接起動する。

```txt
MyProject.exe [runtime-options]
```

### ランタイム引数

| オプション | 意味 |
|---|---|
| `--manifest <PATH>` | 読み込む `manifest.json` を指定する |
| `--debug` | デバッグ機能を有効にする |
| `--locale <LOCALE>` | 実行ロケールを指定する |
| `--start <TAG>` | 指定ラベルまたはタグから開始する |
| `--fullscreen` | フルスクリーンで起動する |
| `--width <NUMBER>` | 起動時ウィンドウ幅を指定する |
| `--height <NUMBER>` | 起動時ウィンドウ高さを指定する |
| `--profile` | プロファイル情報を収集する |

`kes run` の `--` 以降に指定された引数は、CLI では解釈せずランタイムへ渡される。

配布物をユーザーが直接起動した場合、ランタイムは実行ファイルと同じディレクトリまたは `data/` 配下から既定の `manifest.json` を探索する。

## 入力ファイル

Windows ランタイムは、次のファイルを入力として扱う。

| ファイル | 用途 |
|---|---|
| `manifest.json` | 実行に必要な `.klib`、素材、メタ情報を定義する |
| `.klib` | VM が実行する中間表現 |
| 画像素材 | 背景、actor、UI 部品、トランジション素材 |
| 音声素材 | BGM、SE、Voice |
| ランタイム設定 | ウィンドウ、音量、テキスト速度などの初期設定 |

素材解決は `manifest.json` を必須とする。
ランタイムは `assets/bg` などのフォルダ規約から暗黙に素材を探索してはならない。

### manifest の責務

`manifest.json` は、少なくとも次の情報を含む。

| 項目 | 内容 |
|---|---|
| project | プロジェクト名、バージョン |
| entry | エントリポイントとなる `.kel` または VM 実行情報 |
| scripts | 実行対象の `.klib` 一覧。各 script は `.klib` の `module.scriptId`、script path、entry label と対応する |
| assets | 素材 ID、種別、相対パス、メタ情報 |
| locale | 利用可能なロケール、既定ロケール、各言語向け `.klib` バリアントの情報 |
| runtime | ウィンドウ初期値、制作座標系、起動設定 |
| build | CLI バージョン、ビルド日時、ターゲット |

manifest 内の相対パスは、manifest が置かれたディレクトリを基準に解決する。
manifest は `.klib` を列挙または参照し、`.klib` 内の script path、asset ID などを配布物内の script path と素材パスへ解決する。
`.klib` 側は VM 実行契約と安定識別子を持ち、manifest 側は配布パス、asset metadata、locale metadata を所有する。
ランタイムは翻訳作業用の生 `.csv` を直接読み込まない。ローカライズ辞書は build 時に解決され、言語別の `.klib` として出力される。runtime は選択された言語向け `.klib` をそのまま実行する。

## 画面と描画

### 制作座標系

制作座標系は 1920x1080 固定とする。
背景、actor、テキストウィンドウ、選択肢、UI の配置は、この制作座標系に基づいて定義する。

`kes.xml` の `Runtime.WindowWidth` と `Runtime.WindowHeight` は起動時ウィンドウサイズを表す。
制作座標系の幅と高さを変更するものではない。

### 表示スケーリング

ランタイムは、制作座標系のアスペクト比を維持したまま表示座標系へスケーリングする。

| 状態 | 挙動 |
|---|---|
| 表示領域が 16:9 | 表示領域全体へ拡大縮小する |
| 表示領域が横長 | 左右または上下の余白を計算し、制作座標系を中央配置する |
| 表示領域が縦長 | アスペクト比を維持し、余白を黒または設定色で埋める |

マウス座標や選択肢判定は、表示座標系から制作座標系へ逆変換して扱う。

### レイヤー

描画は次の論理レイヤーを持つ。

| レイヤー | 内容 |
|---|---|
| 背景 | `bg` 命令で表示する背景 |
| actor | `show`、`face`、`action_jump` などで制御する actor |
| 効果 | フェード、クロスフェード、画面遷移 |
| テキスト | `say` / `nar` の本文、話者名 |
| 選択肢 | `select` の選択肢 |
| システム UI | メニュー、履歴、セーブ、ロード、設定、デバッグ表示 |

Win2D の描画処理は、毎フレーム現在の VM 状態と演出状態をもとにレイヤー順で行う。

### トランジション

`trans` は、画面遷移を実行する命令である。
v1 では少なくとも次のトランジションを提供する。

| 種類 | 内容 |
|---|---|
| `fade` | フェードイン、フェードアウト |
| `crossfade` | 前画面と次画面のクロスフェード |
| `none` | 即時切り替え |

未知のトランジション名が指定された場合は実行時エラーとする。

## 対応素材形式

v1 では、次の素材形式を正式サポートする。

| 種別 | 形式 |
|---|---|
| 画像 | PNG, JPEG, WebP |
| 音声 | WAV, MP3, OGG |

画像素材は Win2D で描画可能な形式へ読み込む。
音声素材はランタイムの音声基盤で再生可能な形式へ読み込む。
対応形式であっても、破損ファイルや読み込み不能ファイルは実行時エラーとする。

## 音声

音声は、BGM、SE、Voice の3種類のチャンネルとして扱う。

| チャンネル | 用途 | 多重再生 |
|---|---|---|
| BGM | 背景音楽 | 原則1系統 |
| SE | 効果音 | 複数同時再生可 |
| Voice | 台詞音声 | 原則1系統 |

音量は、マスター音量、BGM 音量、SE 音量、Voice 音量を個別に持つ。

`say` / `nar` のタグ付きテキストでは、言語仕様の自動ボイス再生規則に従い Voice を再生する。
該当する Voice 素材が manifest に存在しない場合は警告として扱い、実行は継続する。

クリック進行で現在のテキストをスキップした場合、再生中の Voice は停止する。
BGM は停止しない。

## 入力操作

標準入力操作は次の通りとする。

| 操作 | 挙動 |
|---|---|
| 左クリック / Enter / Space | テキスト送り、選択肢決定 |
| 右クリック / Esc | システムメニュー表示または閉じる |
| Ctrl | 押下中スキップ |
| Tab | オートモード切り替え |
| マウスホイール上 | バックログ表示 |
| 上下キー | 選択肢移動 |
| F11 | フルスクリーン切り替え |

キー割り当ては将来的に設定可能にできる設計とするが、v1 では固定でよい。

## 標準 UI

v1 の Windows ランタイムは、配布用プレイヤーとして次の標準 UI を内蔵する。

| UI | 内容 |
|---|---|
| メッセージウィンドウ | 話者名、本文、クリック待ち表示を表示する |
| 選択肢 | `select` の `case` を一覧表示し、選択を受け付ける |
| バックログ | 表示済みテキストと話者名を確認できる |
| スキップ | 既読または全テキストの高速進行を行う |
| オート | 一定時間後に自動で次へ進む |
| セーブ | 任意スロットへセーブする |
| ロード | セーブスロットから復元する |
| 設定 | 音量、テキスト速度、オート速度、表示設定を変更する |
| タイトル | タイトル画面へ戻る |
| 終了 | アプリケーションを終了する |

UI スキン差し替えは将来拡張とし、v1 ではランタイム内蔵 UI を標準とする。

## VM 連携

ランタイムは VM から発行される命令を受け取り、描画、音声、UI、制御フローへ反映する。

### 主要命令

| 命令 | ランタイム側の責務 |
|---|---|
| `bg` | 背景素材を読み込み、背景レイヤーへ設定する |
| `show` | actor を指定位置へ表示する |
| `face` | actor の表情差分を切り替える |
| `action_jump` | actor にジャンプ動作を実行する |
| `trans` | 画面遷移を実行する |
| `rt_back` | 裏画面への描画準備を行う |
| `rt_front` | 表画面へ反映する |
| `vo` | Voice を明示再生する |
| `say` | 話者付きテキストを表示し、クリック待ちを行う |
| `nar` | ナレーションテキストを表示し、クリック待ちを行う |
| `select` | 選択肢を表示し、選択結果に応じてタグへジャンプする |
| `label` | VM のジャンプ先として扱う |
| `jump` | 指定タグへ VM 実行位置を移す |

命令の構文、型検査、タグ解決は原則として CLI のビルド段階で検証する。
ランタイムでは、素材欠落、読み込み失敗、VM 状態不整合など実行時にしか検出できないエラーを扱う。

## セーブとロード

v1 では、通常セーブ、ロード、オートセーブ、既読情報、ユーザー設定保存を必須とする。

### セーブ対象

セーブデータには、少なくとも次の情報を含める。

| 項目 | 内容 |
|---|---|
| VM 状態 | 実行中の `.klib` の script id、instruction index、コールスタック、変数 |
| 制御状態 | 選択履歴、ジャンプ履歴、現在のロケール |
| 画面状態 | 背景、actor、表情、位置、表示中テキスト、選択肢 |
| 音声状態 | BGM、必要に応じた Voice の再開情報 |
| 既読情報 | 既読テキスト、既読タグ |
| メタ情報 | セーブ日時、表示名、サムネイル、ランタイムバージョン |

ロード直後は、ユーザーがセーブした時点と同じ画面へ戻ることを基本とする。
セーブデータが保持する VM 位置は、配布物上のファイルパスだけに依存せず、`.klib` 上の script id と instruction index を安定参照として扱う。
タグ、選択肢復帰位置、分岐復帰位置も、ビルド時に解決された label と instruction index を基準に復元する。

### セーブ保存先

セーブデータとユーザー設定は、Windows のユーザーデータ領域へ保存する。
配布物ディレクトリが書き込み不可であっても、通常プレイとセーブが可能でなければならない。

保存先の具体パスは実装で定義してよいが、プロジェクト名と発行元を含め、複数ゲーム間で衝突しないようにする。

## 設定保存

ユーザー設定には、少なくとも次の項目を含める。

| 項目 | 内容 |
|---|---|
| masterVolume | マスター音量 |
| bgmVolume | BGM 音量 |
| seVolume | SE 音量 |
| voiceVolume | Voice 音量 |
| textSpeed | テキスト表示速度 |
| autoSpeed | オート進行速度 |
| skipMode | 既読のみスキップ、全スキップ |
| fullscreen | フルスクリーン状態 |
| windowSize | ウィンドウサイズ |
| locale | 選択ロケール |

設定変更は即時反映し、アプリ終了後も保持する。

## 診断とデバッグ

ランタイムは通常配布モードとデバッグモードを分離する。

### 通常配布モード

通常配布モードでは、一般ユーザーに必要な範囲のエラー表示のみを行う。
詳細な VM 位置、内部スタック、素材解決ログなどは画面上に表示しない。

### デバッグモード

`--debug` が指定された場合、次の情報を表示またはログ出力できる。

| 項目 | 内容 |
|---|---|
| FPS | 描画フレームレート |
| VM 位置 | 実行中の `.klib` の script id、instruction index、タグ |
| リソース | 読み込み済み素材、未解決素材 |
| 音声 | 再生中チャンネル、音量 |
| 入力 | 直近の入力イベント |
| ログ | 実行時警告、エラー、プロファイル情報 |

`--profile` が指定された場合は、描画時間、VM 実行時間、素材読み込み時間などの計測情報を収集する。
デバッグ表示やログで元 `.kc` の file、line、column を示す場合は、`.klib` の source mapping を参照する。
source mapping が存在しない場合は、script id と instruction index を fallback 表示として扱う。

## エラーと終了コード

Windows ランタイムは、終了時に CLI の終了コード体系と整合する終了コードを返す。

| 終了コード | 意味 |
|---|---|
| `0` | 正常終了 |
| `1` | 一般エラー |
| `2` | ランタイム引数エラー |
| `5` | 実行時エラー |
| `6` | ファイルまたはディレクトリの入出力エラー |
| `7` | ランタイム起動エラー |

manifest が存在しない、または読み込めない場合は起動エラーとする。
manifest に記載された必須 `.klib` が存在しない場合は入出力エラーとする。
命令実行中に素材が読み込めない場合は、命令の重要度に応じて警告または実行時エラーとする。

## 配布成果物

`kes publish --target windows` は、Windows ランタイムを含む自己完結フォルダを生成し、既定で zip アーカイブを生成する。

```txt
dist/
    windows/
        MyProject/
            MyProject.exe
            data/
                manifest.json
                events/
                    chapter001.klib
                    loc/
                        en/
                            chapter001.klib
                assets/
            licenses/
        MyProject-0.1.0-windows.zip
```

| パス | 内容 |
|---|---|
| `MyProject.exe` | 配布用プレイヤー |
| `data/manifest.json` | ランタイム入力 manifest |
| `data/events/` | `.klib` ファイル |
| `data/assets/` | 画像、音声、UI 素材 |
| `data/events/loc/` | 言語別に compile-time 解決された `.klib` バリアント |
| `licenses/` | ランタイム、ライブラリ、素材のライセンス情報 |

Windows 向け配布物では、`--include-source` が指定されていない限り `.kc` / `.kel` の生ファイルを含めない。

## 受け入れ条件

初期リリースでは、次を満たすことを必須とする。

1. Windows 11 上で `MyProject.exe` を起動できる。
2. `kes run` から `manifest.json` を渡してランタイムを起動できる。
3. 1920x1080 の制作座標系が、ウィンドウ表示とフルスクリーン表示でアスペクト比を維持して描画される。
4. manifest に定義された背景、actor、BGM、SE、Voice を読み込める。
5. `bg`、`show`、`face`、`trans`、`say`、`nar`、`select`、`jump` を実行できる。
6. テキスト送り、選択肢決定、バックログ、スキップ、オートが動作する。
7. 通常セーブ、ロード、オートセーブ、既読情報、ユーザー設定保存が動作する。
8. `--debug` の有無でデバッグ表示と詳細ログの出力が切り替わる。
9. `kes publish --target windows` の zip を展開し、配布フォルダ内の実行ファイルからプレイを開始できる。
